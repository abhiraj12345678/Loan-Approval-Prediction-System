## ▶️ Installation

Clone the repository

```bash
git clone https://github.com/abhiraj12345678/ai-ml-loan-risk-prediction-advisor-app.git
```

Move to project directory

```bash
cd ai-ml-loan-risk-prediction-advisor-app
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
